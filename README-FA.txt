نسخهٔ ۳ — تغییرات رابط کاربری و انتقال بین حساب‌ها

تغییرات این نسخه:
- داشبورد خلوت با میانبرهای آیکن‌دار برای مشتریان، حسابات، خزانه و مدیریت ارزها.
- حذف «مشتری جدید» از داشبورد؛ افزودن مشتری از داخل بخش مشتریان انجام می‌شود.
- بخش مستقل خزانه برای دادوگرفت‌ها، طلب‌ها و قرض‌ها، انتقالات و گزارشات.
- فورم سادهٔ انتقال: حساب اصلی، مبلغ با انتخاب ارز رنگی در کنار مبلغ، نوع طلب/گرفت و حساب «درک».
- در حالت طلب، مبلغ از حساب درک کم و به حساب اصلی اضافه می‌شود؛ در حالت گرفت برعکس.
- انتخاب ارز فقط یک‌بار انجام می‌شود و انتقال به همان ارز ثبت می‌گردد.
- امکان حذف ارزهای سفارشی فقط در صورتی که در معاملات یا انتقالات استفاده نشده باشند.

یادآوری: این نسخه هنوز نیازمند راه‌اندازی Supabase و آزمایش محیط آنلاین است. ورود/ثبت‌نام به‌تنهایی به معنای جداسازی امن شرکت‌ها نیست؛ قبل از استفاده با اطلاعات مالی واقعی، سیاست‌های RLS و جداسازی داده‌ها را بررسی و آزمایش کنید. قابلیت آفلاین این نسخه ذخیرهٔ محلی مرورگر است و همگام‌سازی آفلاین کامل یا شبکهٔ محلی چنددستگاهی در این بسته تضمین نشده است.

حساب‌یار HesabYar — بستهٔ نسخهٔ ۲ — بهبودهای رابط کاربری
======================================

این بسته شامل رابط برنامه، حالت محلی، PWA، کد اتصال Supabase و فایل SQL ساخت جداول و سیاست‌های امنیتی است.

امکانات موجود در این نسخه:
- ثبت، ویرایش و جست‌وجوی مشتریان
- ثبت طلب، گرفت و پرداخت/دریافت
- انتقال بین حساب مشتریان با ارز یکسان یا متفاوت، نرخ و سند قابل چاپ
- ارزهای پیش‌فرض و افزودن ارز جدید
- نرخ‌های دستی خرید/فروش/توافقی
- حساب مشتریان و مانده جداگانه به تفکیک ارز
- انتخاب گروهی و حذف گروهی معاملات
- گزارش بر اساس بازهٔ تاریخ و مشتری، چاپ/ذخیره PDF از مرورگر، خروجی CSV
- پشتیبان JSON و بازیابی
- نصب به‌عنوان PWA
- ساختار Supabase با Row Level Security برای تفکیک داده‌های هر کاربر
- حذف کامل سند انتقال با تأیید کاربر، علاوه بر امکان لغو سند
- حالت روشن، شب و مطابق تنظیم دستگاه
- تنظیم نوع فعالیت شرکت (صرافی، فروشگاه یا حسابداری عمومی) برای پروفایل برنامه
- ذخیره نام مدیر و عکس پروفایل در اطلاعات محلی

محدودیت‌های مهم نسخهٔ ۲:
نسخهٔ آنلاین تا وقتی پروژهٔ Supabase ساخته نشده و SQL اجرا و اتصال تنظیم نشده، فعال نیست. GitHub Pages به تنهایی دیتابیس و ورود امن فراهم نمی‌کند. حالت محلی اطلاعات را فقط در همان مرورگر/دستگاه نگه می‌دارد. انتقال دادهٔ موجود محلی به حساب آنلاین هنوز باید به‌صورت واردسازی کنترل‌شده انجام شود؛ قبل از استفادهٔ واقعی حتماً پشتیبان بگیرید. انتخاب نوع فعالیت فعلاً تنظیم پروفایل است و به معنی تکمیل ماژول‌های انبارداری/فروشگاه یا حسابداری دوبل نیست. ترجمهٔ کامل سه‌زبانه، همگام‌سازی آفلاین واقعی، مدیریت کاربران و نقش‌ها، لایسنس و ایزوله‌سازی چندشرکتی هنوز نیاز به توسعه و آزمایش جداگانه دارد.

راه‌اندازی آنلاین:
1. به https://supabase.com بروید و یک پروژه بسازید.
2. از Project Settings / API، Project URL و کلید عمومی anon/publishable را بردارید. service_role را هرگز استفاده نکنید.
3. در SQL Editor فایل supabase-schema.sql را کامل اجرا کنید.
4. در Authentication تنظیمات تأیید ایمیل را مطابق نیاز تنظیم کنید.
5. فایل‌های index.html، manifest.webmanifest، icon.svg و sw.js را روی یک میزبان HTTPS مثل GitHub Pages قرار دهید.
6. در برنامه، بخش «تنظیمات» را باز کرده URL و کلید عمومی را وارد و ذخیره کنید؛ سپس «ورود / ثبت‌نام» را باز کنید.
7. ابتدا با یک حساب آزمایشی، مشتری و معامله آزمایشی بسازید و با حساب دوم بررسی کنید که اطلاعات حساب اول دیده نمی‌شود.

نکتهٔ فنی:
این نسخهٔ آغازین است و قبل از استفادهٔ عملیاتی در صرافی باید تست‌های پذیرش، بازیابی اطلاعات، امنیت، و صحت محاسبات مالی با دادهٔ آزمایشی تکمیل شوند. هیچ اطلاعات واقعی مشتری را در تست اولیه وارد نکنید.
